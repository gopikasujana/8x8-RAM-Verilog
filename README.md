# 8×8 RAM using Verilog HDL

## Project Overview

This project implements an **8×8 Single-Port RAM** using **Verilog HDL**.

The RAM supports:
- Synchronous Write
- Synchronous Read
- Asynchronous Reset

---

## Specifications

| Feature | Description |
|---------|-------------|
| Memory Size | 8 × 8 |
| Data Width | 8 bits |
| Address Width | 3 bits |
| Read | Synchronous |
| Write | Synchronous |
| Reset | Asynchronous |
